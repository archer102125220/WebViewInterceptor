🚀 WebServer 跳轉測試控制台

此頁面用於測試雙平台 WebView 處理帶有非同步延遲、302 重新導向與表單中繼跳轉情境。

實驗 1：302 延遲重新導向 (a tag _blank)

點擊 <a target="_blank"> 跳轉到 /redirect (後端延遲 2 秒回傳 302)。

開啟 302 測試 (a tag)

實驗 2：302 延遲重新導向 (window.open)

使用 window.open('/redirect', '_blank') 跳轉到 /redirect。

實驗 3：中繼頁面 API + Form GET 跳轉 (常規 0.6 秒)

以 target="_blank" 開啟 /form-bridge?method=GET，中繼頁載入時於 <script> 內直接呼叫 API 取得參數，並透過 Form GET 跳轉到結果頁。
