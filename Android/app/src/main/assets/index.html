🟢 雙平台皆成功：非同步與 Event Loop (無視窗開啟限制)

🟢 雙平台皆成功攔截：Form GET 原頁跳轉 (完全繞過非同步限制)

實測證實：Form GET (target="_self") 完全不受 5 秒寬限期與非同步事件限制，完美跳轉且能被攔截。

🟡 平台限制與差異：只有某一方能成功攔截或放行

🟡 Form POST 原頁跳轉 (Android 穿透, iOS 攔截無 Body)

實測證實：POST 也繞過非同步限制，但 Android 原生無法攔截，iOS 雖攔截但 IPC 限制導致 Body 為 nil。

🔴 雙平台皆失效 (攔截死角與超時封殺)
